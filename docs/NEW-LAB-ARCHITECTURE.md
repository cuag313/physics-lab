# 新实验台架构（NB级）

## 概述

2026-08-13 重构的物理实验仿真系统，对标NB（NOBOOK）仿真实验平台。

核心理念：**不是做54个实验动画，而是做一个仪器+引擎+场景的仿真平台。**

## 核心架构

### 三层分离

```
┌─────────────────────────────────────┐
│          UI层 (ExperimentBench)      │
│  工具箱 | Canvas实验台 | 数据面板     │
├─────────────────────────────────────┤
│          场景层 (PhysicsScene)        │
│  仪器管理 | 导线连接 | 引擎驱动       │
├─────────────────────────────────────┤
│          引擎层 (CircuitEngine)       │
│  MNA矩阵求解 | 电路拓扑 | 节点分析    │
├─────────────────────────────────────┤
│          仪器层 (InstrumentBase)      │
│  端口 | 参数 | 渲染 | 碰撞检测        │
└─────────────────────────────────────┘
```

### 仪器系统

每个仪器继承 `InstrumentBase`：
- **端口(Port)**：仪器的连接点（正极、负极、左、右等）
- **参数(Params)**：可调参数（电阻值、电动势等），带min/max/step
- **状态(State)**：运行时状态（亮度、指针角度等）
- **渲染(render)**：Canvas2D拟物化绘制
- **物理更新(update)**：每帧调用，更新状态
- **碰撞检测(containsPoint)**：点击/拖拽判定

### 电路引擎（MNA求解器）

改进节点分析法(Modified Nodal Analysis)：

1. **拓扑构建**：从仪器端口和导线构建电路图
2. **节点编号**：用并查集合并相连端口
3. **矩阵构建**：电导矩阵G + 电压源约束B + 激励向量s
4. **高斯消元**：求解 Gx = s
5. **结果提取**：更新各仪器的电压/电流

支持：串联、并联、混联、电压源、电流表、电压表、滑动变阻器

### 交互系统

- **点击空白**：取消选择
- **点击仪器**：选中（显示参数）
- **拖拽仪器**：移动位置
- **点击端口**：开始连线
- **点击另一个端口**：完成连线
- **点击开关**：切换通断
- **拖拽滑变器滑片**：调节电阻比例
- **右键**：删除仪器
- **Delete/Backspace**：删除选中仪器
- **ESC**：取消连线

### 渲染系统

统一Canvas2D，不用Three.js：
- 网格背景 + 坐标轴 + 刻度标注
- 坐标变换（世界坐标 ↔ 屏幕坐标）
- 仪器拟物化绘制（电池符号、电阻锯齿、灯泡发光、表盘指针）
- 导线绘制 + 连线预览
- DPR适配（高分屏清晰）

## 预设实验

| 名称 | 描述 |
|------|------|
| 简单电路 | 电池→开关→灯泡 |
| 串联电路 | 两个灯泡串联，电流相同 |
| 并联电路 | 两个灯泡并联，电压相同 |
| 伏安法测电阻 | 电流表串联+电压表并联 |
| 滑动变阻器（限流） | 滑变器串联调节电流 |

## 与旧系统的区别

| 旧系统 | 新系统 |
|--------|--------|
| 54个独立组件 | 统一仪器+引擎+场景 |
| 每个实验硬编码物理 | 引擎统一求解 |
| Three.js + Canvas2D混用 | 统一Canvas2D |
| 仪器不可复用 | 仪器是独立实体 |
| 无连线 | 端口+导线连接 |
| 公式+静态渲染 | 实时仿真循环 |
