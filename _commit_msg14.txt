3D 实验台：导线终于连上、器材立起、转台限幅、侧栏立体化

本轮针对用户提出的三条缺陷：

1. 桌面移动太灵敏、活动范围太大
   - 移除空白处拖拽即转台的行为，改为右下角「转台」圆形把手（按住才转）
   - yaw 限幅 ±45°、pitch 限幅平视 0 ~ 俯视 0.62rad，惯性积分同样夹紧

2. 3D 仪器躺平、线没连接、物理逻辑没接上
   - 电流表/电压表/电能表/验电器改为立式（两步 rotateX，面板朝 -Z，
     UV/指针/接线柱热区/剖视 inner 全部按立式重算）
   - 导线真正的病根是 Verlet 粒子受重力下垂后穿到桌面下方，
     被桌面挡住 → 整根线"看不见"，表现为"线都没连接"；
     simulate 里加台面约束（y 不低于 0.02），线自然贴着台面走
   - 另修三处导线不显示的结构性缺陷：
     - Mesh 开启视锥剔除时用初始全零包围球判断，一离开原点就被裁掉
       → frustumCulled = false
     - equips 的 key 与导线里的 cid 类型/前缀不一致导致取端子永远 null
       → 新增 findEquip 按字符串兜底比对
     - 取不到端子时兜底到器材位置，避免整条线被 continue 跳过而永不 pin
   - 线径 0.03 → 0.045，台面上看得清

3. 3D 视图左侧仍是 2D 器件
   - 新增 .esvg-palette.is3d：侧栏收窄、竖向卡片、等轴透视 +
     投影的立体图标

相机：CAM_ELEV 0.56 / CAM_BACK 0.83 / CAM_DIST0=12 / camTarget.y 0.55，
新增 frameToComps，首帧把镜头对准器材重心，解决"开局对着空桌角"。
